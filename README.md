# NOVAPLAY

Монгол хэлээр хийсэн кино, анимэ, цувралын стриминг платформ (ажлын нэр: NOVAPLAY).

## Одоогийн төлөв

Эхний үе шат: каталогийн суурь, нүүр хуудас, дэлгэрэнгүй хуудас, хайлт, өгөгдлийн сангийн схем.
Төлбөр болон бодит видео түгээлт **холбогдоогүй**. Дэлгэрэнгүйг [docs/STATUS.md](docs/STATUS.md)-ээс үзнэ үү.

## Ажиллуулах

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck && npm run lint && npm test && npm run test:db && npm run build
```

Supabase тохируулаагүй үед сайт "Жишээ каталог" (зохиомол, зураггүй) өгөгдлөөр ажиллана, дээд талд нь тэр нь тодорхой харагдана.
`.env.example`-ийг `.env.local` болгон хуулж Supabase URL болон anon key-г оруулбал лицензтэй каталог руу шилжинэ.

## Бүтэц

| Зам | Агуулга |
| --- | --- |
| `src/app/(site)` | Нүүр, Кино, Анимэ, Цуврал, Төрөл, Хайлт, Миний жагсаалт, дэлгэрэнгүй хуудас |
| `src/components` | `ui`, `brand`, `layout`, `content` |
| `src/lib/catalog` | Каталогийн интерфэйс, Supabase болон жишээ өгөгдөл, шүүлт, хайлт |
| `src/lib/video` | `VideoProvider` интерфэйс (адаптер бүртгээгүй) |
| `src/styles/tokens.css` | Дизайн токен |
| `supabase/migrations` | Схем, RLS, лицензийн хаалт, анхны төрлүүд |
| `scripts/check-migrations.mjs` | Миграцийг санах ойн Postgres дээр ажиллуулж дүрмүүдийг шалгана |
| `docs/` | Архитектур, ERD, төлөв |

## Лицензийн дүрэм

`content.status` нь `published` болох бол `content_rights` дээр батлагдсан, хугацаа нь дуусаагүй, Монгол (MN) нутаг дэвсгэрийг хамарсан эрх заавал байх ёстой (өгөгдлийн сангийн trigger). Сайт зөвхөн `public_content` view-ээс уншина.
