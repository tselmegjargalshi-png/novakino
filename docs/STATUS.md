## Зориудаар хийгээгүй

- **Бодит видео, тоглуулагч**: товч байхгүй. `VideoProvider` интерфэйс бий, адаптер бүртгээгүй (Phase D).
- **Төлбөр**: схем бэлэн, ямар ч gateway холбоогүй (Phase F).
- **Нэвтрэлт, профайл**: байхгүй. "Миний жагсаалт" одоогоор зөвхөн төхөөрөмж дээр (localStorage) хадгалагдана (Phase C).
- **Дараах нүүрний мөрүүд**: "Үргэлжлүүлэн үзэх", "Танд санал болгох" (бүртгэл хэрэгтэй), "Хамгийн их үзсэн", "Тренд болж буй" (үзэлтийн өгөгдөл хэрэгтэй). Өгөгдөлгүйгээр хуурамчаар харуулахгүй тул нүүр хуудаснаас түр хасагдсан. `homepage_collections` хүснэгт дэх тохиргоо бэлэн.
- **Админ самбар**: Phase E. Одоо бүтээл оруулахдаа SQL/Supabase Studio ашиглана.
- **Жишээ каталог**: зөвхөн Supabase тохируулаагүй үед харагдах зохиомол 18 бүтээл, зураггүй (брэндийн градиент).

## Үүнийг хийхэд хэрэгтэй (хэрэглэгчээс)

1. Supabase төсөл үүсгэж `supabase/migrations`-ийг ажиллуулах, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`-г Vercel дээр тохируулах. Зургийн нийтийн `artwork` bucket үүсгэх.
2. Лицензтэй анхны бүтээлүүд болон гэрээний нөхцөл.
3. Видео провайдер (Mux эсвэл Cloudflare Stream) сонголт.
